# TaskFlow - Full Stack Task Management Application

A responsive Full Stack Task Management application built with **React 19**, **Node.js/Express**, and **MongoDB Atlas**.

---

## 🚀 Live Access

- **Frontend Application**: [http://localhost:3000](http://localhost:3000)
- **Backend API Server**: [http://localhost:5000](http://localhost:5000)
- **API Health Check**: [http://localhost:5000/api/health](http://localhost:5000/api/health)
- **Tasks Endpoint**: [http://localhost:5000/api/tasks](http://localhost:5000/api/tasks)

---

## 🛠️ Tech Stack

- **Frontend**: React 19, Modern CSS (Responsive Grid/Flexbox, custom CSS variables)
- **Backend**: Node.js, Express.js, CORS, Dotenv
- **Database**: MongoDB Atlas (`task-assessments-db`), Collection: `tasks`, ODM: Mongoose 7

---

## 🗄️ Database Schema

### Database: `task-assessments-db`
### Collection / Table: `tasks`

```javascript
{
  _id: ObjectId,           // Unique identifier generated by MongoDB
  title: {
    type: String,
    required: true,
    trim: true             // Task title / summary
  },
  description: {
    type: String,
    trim: true,
    default: ''            // Optional additional task details
  },
  completed: {
    type: Boolean,
    default: false         // Completion status flag
  },
  priority: {
    type: String,
    enum: ['low', 'medium', 'high'],
    default: 'medium'      // Priority badge
  },
  createdAt: ISODate,      // Timestamp created
  updatedAt: ISODate       // Timestamp last updated
}
```

## 📡 REST API Documentation

| Method | Endpoint | Description | Request Body |
| :--- | :--- | :--- | :--- |
| **GET** | `/api/tasks` | Get all tasks (ordered newest first) | None |
| **GET** | `/api/tasks/:id` | Get single task by ID | None |
| **POST** | `/api/tasks` | Create a new task | `{ "title": "string", "description": "string", "priority": "low"\|"medium"\|"high" }` |
| **PUT** | `/api/tasks/:id` | Update task fields | `{ "title": "string", "description": "string", "completed": boolean, "priority": "..." }` |
| **PATCH**| `/api/tasks/:id/toggle` | Toggle task completion status | None |
| **DELETE**| `/api/tasks/:id` | Delete a task by ID | None |
| **GET** | `/api/health` | Service health status check | None |

## 💻 Setup & Run Instructions

### Prerequisites
- Node.js (v18+)
- npm

### 1. Install Dependencies
```bash
# Install server dependencies
cd server
npm install

# Install client dependencies
cd ../client
npm install
```

### 2. Environment Configuration
Create or inspect `server/.env`:
```env
MONGO_URI=mongodb+srv://mikhlas78690:newGmail786@cluster0.8ndnqrm.mongodb.net/task-assessments-db?retryWrites=true&w=majority
PORT=5000
```

### 3. Running the Application
From the root directory:
```bash
# Start backend server (Port 5000)
npm run server

# In another terminal, start React client (Port 3000)
npm run client
```

Or run both from their respective directories:
- **Server**: `cd server && npm start`
- **Client**: `cd client && npm start`

## ✨ Features Implemented

1. **Responsive User Interface**:
   - Modern, clean card-based layout with responsive mobile/tablet/desktop CSS.
   - Real-time statistics counters (Total Tasks, Pending, Completed).
   - Filter tabs: All, Pending, Completed, plus dynamic search bar.
   - Priority indicators (Low, Medium, High).
   - Animated notification alerts for actions (add, edit, toggle, delete).

2. **Full CRUD & Database Sync**:
   - **Add Task**: Validates title input and creates new task in MongoDB.
   - **Edit Task**: Inline edit mode allowing updates to title, description, and priority.
   - **Delete Task**: Removes task from MongoDB collection and UI instantly.
   - **Mark as Completed**: Checkbox toggle updating `completed: true/false` directly in database.
